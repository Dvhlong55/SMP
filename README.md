# SMP - My Personal Website 🌐

Welcome to the source code of Long Hoang's personal website! This is a small space where I store and share my learning journey, life stories, and especially my strong passion for Mathematics.

## Project Structure

The website is divided into main categories for easy content management:

- **`About-Me/`**: A detailed introduction about myself, my future goals, and my career path.
- **`Math/`**: A dedicated space for Mathematics. This is where I share documents, notes on math problems, in-depth theories, and study experiences.
- **`Non-Math/`**: Topics outside of Math. This section contains programming projects, algorithm notes (like C++, Python), explorations into Artificial Intelligence (AI), and other technologies.
- **`My-Life/`**: Daily moments, memories, and personal life stories.
- **`css/`** & **`js/`**: Contains stylesheets and logic scripts that keep the website running smoothly.
- **`image/`**: Stores all the image resources used on the website.
- **`index.html`**: The main homepage.
