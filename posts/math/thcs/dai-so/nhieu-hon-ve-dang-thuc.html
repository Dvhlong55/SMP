$\S$ Nhiều Hơn Về Đẳng Thức

Secrets of Mathematical Principles — Chuyên Toán THCS

Chuyên đề Đại số · Phân thức và Biến đổi đẳng thức

Kỹ thuật biến đổi then chốt: Khai thác điều kiện ràng buộc tích $xyz = k$ bằng cách đổi biến đồng bậc, kỹ thuật thế điều kiện $ab + bc + ca = 1 \implies 1 + a^2 = (a+b)(a+c)$, và ý tưởng đa thức nội suy Lagrange trong chứng minh đẳng thức phân thức.

Bài 1

Rút gọn biểu thức sau (với $a, b, c$ đôi một khác nhau):

$$P = \frac{(d - b)(d - c)}{(a - b)(a - c)} + \frac{(d - c)(d - a)}{(b - c)(b - a)} + \frac{(d - a)(d - b)}{(c - a)(c - b)}$$

Bài 2

Cho $x, y, z$ là các số thực dương thỏa mãn $xyz = 4$. Chứng minh rằng:

$$\frac{15\sqrt{x}}{3\sqrt{x} + \sqrt{xy} + 2} + \frac{5\sqrt{y}}{\sqrt{yz} + \sqrt{y} + 3} + \frac{10\sqrt{z}}{3\sqrt{zx} + 2\sqrt{z} + 2} = 5$$

Bài 3

Cho $x, y, z$ là các số thực dương thỏa mãn $xyz = x + y + z$. Chứng minh rằng:

$$\frac{x}{1 + x^2} + \frac{2y}{1 + y^2} + \frac{3z}{1 + z^2} = \frac{xyz(5x + 4y + 3z)}{(x + y)(y + z)(z + x)}$$

Bài 4

Cho $x, y, z$ thỏa mãn $x + y + z + \sqrt{xyz} = 4$. Chứng minh rằng:

$$\sqrt{x(4 - y)(4 - z)} + \sqrt{y(4 - z)(4 - x)} + \sqrt{z(4 - x)(4 - y)} - \sqrt{xyz} = 8$$

Bài 5

Cho ba số $a, b, c$ thỏa mãn $c^2 + 2(ab - bc - ca) = 0$, với $b \neq c$ và $a + b \neq c$. Chứng minh rằng:

$$\frac{2a^2 - 2ac + c^2}{2b^2 - 2ab + c^2} = \frac{a - c}{b - c}$$

Bài 6

Cho trước $a, b \in \mathbb{R}$. Gọi $x, y$ là hai số thực thỏa mãn:

$$\begin{cases} x + y = a + b \\ x^3 + y^3 = a^3 + b^3 \end{cases}$$

Chứng minh rằng: $x^{2011} + y^{2011} = a^{2011} + b^{2011}$.

Bài 7

Cho ba số thực dương $a, b, c$ thỏa mãn $ab + bc + ca = 1$. Tính giá trị của biểu thức:

$$T = a\sqrt{\frac{(1 + b^2)(1 + c^2)}{1 + a^2}} + b\sqrt{\frac{(1 + c^2)(1 + a^2)}{1 + b^2}} + c\sqrt{\frac{(1 + a^2)(1 + b^2)}{1 + c^2}}$$

Bài 8

Cho $a, b, c$ là các số thực khác $0$ thoả mãn $\frac{1}{a} + \frac{1}{b} + \frac{1}{c} = \frac{2026}{abc}$. Tính giá trị biểu thức:

$$A = \frac{1}{a^2 + 2bc - 2026} + \frac{1}{b^2 + 2ac - 2026} + \frac{1}{c^2 + 2ab - 2026}$$
