$\S$ Tỉ Lệ Thức & Dãy Tỉ Số Bằng Nhau

Secrets of Mathematical Principles — Chuyên Toán THCS

Chuyên đề Đại số · Bài tập bồi dưỡng

Kiến thức trọng tâm: Tính chất của dãy tỉ số bằng nhau: $$\frac{a_1}{b_1} = \frac{a_2}{b_2} = \dots = \frac{a_n}{b_n} = \frac{k_1 a_1 + k_2 a_2 + \dots + k_n a_n}{k_1 b_1 + k_2 b_2 + \dots + k_n b_n}$$ Kỹ thuật đặt ẩn phụ $k$ (phương pháp chuẩn hóa giá trị tỉ số) và khai thác tính đối xứng của các hằng đẳng thức đáng nhớ.

Bài 1

Tìm các số $x, y, z$ biết rằng:

$$\frac{3x + 25}{144} = \frac{2y - 169}{25} = \frac{z + 144}{169} \quad \text{và} \quad 3x + 2y + z = 169$$

Bài 2

Tìm các số $x, y$ biết rằng:

$$\frac{2x + 1}{5} = \frac{3y - 2}{7} = \frac{2x + 3y - 1}{6x}$$

Bài 3

Cho dãy tỉ số $\frac{a_1}{a_2} = \frac{a_2}{a_3} = \dots = \frac{a_n}{a_1}$ với $a_1 + a_2 + \dots + a_n \neq 0$ và $a_1 = -\sqrt{5}$. Tính giá trị của $a_2, a_3, \dots, a_n$.

Bài 4

Cho ba số $a, b, c \neq 0$ thỏa mãn hệ:

$$\begin{cases} a + b + c = 1 \\ a^2 + b^2 + c^2 = 1 \\ \frac{x}{a} = \frac{y}{b} = \frac{z}{c} \end{cases}$$

Chứng minh rằng: $xy + yz + zx = 0$.

Bài 5

Cho $a, b, c, d$ thỏa mãn $b$ là trung bình cộng của $a$ và $c$, đồng thời $\frac{1}{c} = \frac{1}{2}\left(\frac{1}{b} + \frac{1}{d}\right)$. Chứng minh rằng bốn số lập thành tỉ lệ thức $\frac{a}{b} = \frac{c}{d}$.

Bài 6

Cho $a, b, c$ thỏa mãn $a + b + c = 0$ và $a^2 = (a + c + 1)(a + b - 1)$. Tính giá trị của $A = a^2 + b^2 + c^2$.

Bài 7

Cho $a, b, c$ đôi một phân biệt thỏa mãn $a^3 + b^3 + c^3 = 3abc$ và $abc \neq 0$. Chứng minh rằng:

$$\frac{ab^2}{a^2 + b^2 - c^2} + \frac{bc^2}{b^2 + c^2 - a^2} + \frac{ca^2}{c^2 + a^2 - b^2} = 0$$

Bài 8

Phân tích đa thức thành nhân tử:

$$P = (a + b + c)^2 + (a - b + c)^2 - 4b^2$$

Bài 9

Cho hai số thực phân biệt $a, b$ thỏa mãn $a^3 + b^3 = a^2b^2(ab - 3)$. Tính giá trị của biểu thức $T = a + b - ab$.

Bài 10

Cho $a, b, c$ là các số thực thỏa mãn $a + b + c = 1$. Tính giá trị của biểu thức:

$$A = a^3 + b^3 + c^3 - 3(ab + c)(c - 1)$$

Bài 11

Cho các số thực $a, b, c$ thỏa mãn hệ:

$$\begin{cases} a + b - 2c = 0 \\ 2ab - bc - ca = 0 \end{cases}$$

Chứng minh rằng: $a = b = c$.
